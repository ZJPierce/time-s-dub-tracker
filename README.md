# It's Time S Dub — parlay tracker

Live sweat board for the group parlay. Stats come from ESPN's public scoreboard and box scores (relayed by `api/espn.js`); each leg's hit chance is computed in the page from its DraftKings price, current stats and time left.

Edit picks, prices and usernames in the `CONFIG` block at the top of the script in `index.html`. Add `#demo` to the URL to watch a simulated game.
